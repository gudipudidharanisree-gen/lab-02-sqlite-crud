## Project Description
This project demonstrates SQLite database integration with Node.js and Express.js.

## Technologies Used
- Node.js
- Express.js
- SQLite
- JavaScript

## CRUD Operations
1. GET – Retrieve all books.
2. GET by ID – Retrieve a specific book.
3. POST – Add a new book.
4. PUT – Update an existing book.
5. DELETE – Delete a book.

## How to Run
1. Install dependencies using `npm install`.
2. Start the server using `npm run dev`.
3. Open `http://localhost:3000/books/`.
